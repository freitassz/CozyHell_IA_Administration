# Sistemas do jogo

| Sistema | Estado | Resumo |
|---|---|---|
| Biomas | 🟡 quase pronto | 3 biomas: **Planície**, **Floresta**, **Pedreira** (minérios) |
| Geração procedural | 🟡 quase pronta | — |
| Construção | 🟡 em desenvolvimento, baixa prioridade | base opcional; estações (bancada, bigorna) já existem |
| Venda | ✅ existe | caixa achada no mapa → proposta: virar estação fabricável |
| Máquina caça-níquel | ✅ | sorteia armas; repetida vira sucata |
| Spawn de inimigos | ✅ | natural pelo mapa + **pilares** que spawnam ao interagir |
| Spawn de boss | 🟡 | **pilares de boss** com oferenda (hoje só por ovo no criativo) |
| Sementes que viram inimigo | ❓ | ver R02 em [revisao.md](../jogo/revisao.md) |

Detalhes do loop: [docs/jogo/loop.md](../jogo/loop.md).
