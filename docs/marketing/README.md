## Regras deste chat
- Só divulgar o que **existe e funciona**. O que é ⏳ pode aparecer como "em desenvolvimento", nunca como pronto.
- Ideia de marketing que mude o jogo (ex.: priorizar co-op, demo) vira **sugestão para o chat de criação** — registrar em [tarefas.md](tarefas.md) na seção "Levar para o chat de criação".
- Toda descoberta com número (views, wishlists, seguidores) vai para [aprendizados.md](aprendizados.md).
