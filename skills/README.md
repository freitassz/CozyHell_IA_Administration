# Skills do projeto (cópias atualizadas)

Estas são as versões **atualizadas** das duas skills do CozyHell. As skills ficam na conta do claude.ai e **não** são atualizadas automaticamente por aqui: é preciso **enviar** a nova versão.

| Skill | Arquivo para enviar |
|---|---|
| `cozyhell-prompts-ziva` | `cozyhell-prompts-ziva.zip` |
| `lowpoly-game-3d-blender` | `lowpoly-game-3d-blender.zip` |

## Como atualizar
1. claude.ai → **Configurações** → **Capacidades** (Skills).
2. Na skill, use a opção de substituir/enviar nova versão (ou remova a antiga e envie o `.zip`).
3. Use o `.zip` desta pasta (dentro dele: `<nome>/SKILL.md`).

Sempre que o projeto mudar bastante, peça para o chat de administração atualizar estes arquivos e reenvie.
